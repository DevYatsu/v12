# v12 Embedding API Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A convenient, documented developer API (`v12-api` crate) that lets any Rust app configure a `Runtime`, spawn isolated `Context`s (one engine each), register Rust closures as host functions, call JS from the host, and pump the microtask loop.

**Architecture:** New facade crate `crates/v12-api` wrapping `v12-engine::Engine`. One `Context` = one `Engine` (v1 single-realm constraint, `CONTEXT.md:12`); a `Runtime` is a factory that stamps out configured `Context`s. Engine-internal changes are limited to: richer value marshalling, closure-capable native dispatch, retained-program host→JS calls. Everything stays single-threaded (`Rc`/`RefCell`), matching the existing mutator model.

**Tech Stack:** Rust 2024 (rust-version 1.90), cargo workspace, `cargo nextest` for tests.

**Spec:** `CONTEXT.md` (ubiquitous language, v1 single-realm constraint) + repo recon in this session (signatures below verified against `crates/v12-engine/src/engine.rs`, `value.rs`, `builtins/mod.rs`, `crates/v12-interp/src/lib.rs`).

## Global Constraints

- All code: `#![forbid(unsafe_code)]` (workspace convention; JIT mmap layer excepted).
- Public API lives in the new crate `crates/v12-api` (lib name `v12_api`); it must not re-export raw `Interp`/bytecode types.
- Handles never escape the crate boundary; only `JsValue`/typed host values cross it (existing rule in `value.rs` header).
- Single-threaded: no `Send`/`Sync` promises on `Context`/`Runtime`.
- Tests: `cargo nextest run --workspace` must stay green; new tests live with their crate.
- Follow existing doc-comment style: `///` on every public item, `#[must_use]` where the existing code uses it.

```rust
// crates/v12-api/src/context.rs
//! The embedder-facing execution context.

use v12_engine::{Engine, FromValue};

use crate::error::V12Error;

/// An isolated JavaScript execution context.
///
/// Each `Context` owns its own heap, realm, and job queue. Contexts share
/// nothing; spawning one is as cheap as [`Context::new`]. Contexts are not
/// `Send`: drive each one from the thread that created it.
pub struct Context {
    engine: Engine,
}

impl Default for Context {
    fn default() -> Self {
        Self::new()
    }
}

impl Context {
    /// Creates a context with default configuration.
    #[must_use]
    pub fn new() -> Self {
        Self { engine: Engine::new() }
    }

    /// Evaluates `source` as a script and converts the result to `T`.
    ///
    /// Note: current `Engine::eval` returns `undefined` for normal script
    /// completions, so extract values via an explicit trailing expression
    /// is only meaningful once engine eval returns completion values; the
    /// typed conversion of `undefined` yields `None` for most `T`.
    pub fn eval<T: FromValue>(&mut self, source: &str) -> Result<T, V12Error> {
        self.engine
            .eval(source)
            .map_err(|thrown| V12Error { message: self.engine.to_display_string(thrown) })
            .and_then(|value| {
                T::from_value(self.engine.heap(), value)
                    .ok_or_else(|| V12Error { message: "type mismatch converting result".to_string() })
            })
    }
}
```

```rust
impl<T: ToValue> ToValue for Option<T> {
    fn to_value(&self, heap: &mut Heap) -> JsValue {
        match self {
            Some(v) => v.to_value(heap),
            None => JsValue::null(),
        }
    }
}

impl<T: FromValue> FromValue for Option<T> {
    fn from_value(heap: &Heap, value: JsValue) -> Option<Self> {
        if value.is_null() || value.is_undefined() {
            return Some(None);
        }
        T::from_value(heap, value).map(Some)
    }
}

impl<T: ToValue> ToValue for Vec<T> {
    fn to_value(&self, heap: &mut Heap) -> JsValue {
        let items: Vec<JsValue> = self.iter().map(|v| v.to_value(heap)).collect();
        // Allocate exactly the way builtins/array.rs allocates arrays.
        let arr = heap.alloc(v12_heap::JsObject {
            kind: v12_heap::KIND_ARRAY,
            elements: items,
            prototype: None,
            ..Default::default()
        });
        JsValue::object(arr)
    }
}

impl<T: FromValue> FromValue for Vec<T> {
    fn from_value(heap: &Heap, value: JsValue) -> Option<Self> {
        let obj = value.as_object()?;
        let o = heap.get(obj);
        if o.kind != v12_heap::KIND_ARRAY {
            return None;
        }
        o.elements.iter().map(|&v| T::from_value(heap, v)).collect()
    }
}

impl ToValue for u64 {
    fn to_value(&self, _heap: &mut Heap) -> JsValue {
        JsValue::from_f64(*self as f64)
    }
}

impl FromValue for u64 {
    fn from_value(_heap: &Heap, value: JsValue) -> Option<Self> {
        let n = value.as_f64()?;
        if n >= 0.0 && n.fract() == 0.0 && n <= u64::MAX as f64 {
            Some(n as u64)
        } else {
            None
        }
    }
}
```

Adjust field/constructor names to the real `JsObject`/`JsValue` API if the compiler disagrees (e.g. `as_object` may be named differently — check `crates/v12-heap/src/lib.rs`). `Handle<JsObject>` reading follows the pattern in `FromValue for String` (`value.rs:104-106`): `heap.get(handle)`.

```rust
// crates/v12-api/src/runtime.rs
//! Runtime factory: stamps out isolated, configured contexts.

use v12_heap::GcPolicy;

use crate::context::Context;

/// Builder for a [`Runtime`].
#[derive(Clone)]
pub struct RuntimeBuilder {
    gc_policy: GcPolicy,
}

impl Default for RuntimeBuilder {
    fn default() -> Self {
        Self { gc_policy: GcPolicy::default() }
    }
}

impl RuntimeBuilder {
    /// Sets the GC policy for every context spawned by this runtime.
    #[must_use]
    pub fn gc_policy(mut self, policy: GcPolicy) -> Self {
        self.gc_policy = policy;
        self
    }

    /// Builds the runtime.
    #[must_use]
    pub fn build(self) -> Runtime {
        Runtime { gc_policy: self.gc_policy }
    }
}

/// A factory for isolated [`Context`]s sharing one configuration.
///
/// A `Runtime` holds no mutable engine state; contexts are fully independent.
#[derive(Clone)]
pub struct Runtime {
    gc_policy: GcPolicy,
}

impl Default for Runtime {
    fn default() -> Self {
        RuntimeBuilder::default().build()
    }
}

impl Runtime {
    /// Starts configuring a runtime.
    #[must_use]
    pub fn builder() -> RuntimeBuilder {
        RuntimeBuilder::default()
    }

    /// Spawns a new isolated context.
    #[must_use]
    pub fn spawn(&self) -> Context {
        Context::with_gc_policy(self.gc_policy.clone())
    }
}
```

```rust
/// A host function implemented as a capturing Rust closure.
pub type HostClosure = std::rc::Rc<
    std::cell::RefCell<dyn FnMut(&mut Heap, JsValue, &[JsValue]) -> Result<JsValue, JsValue>>,
>;

#[derive(Clone)]
enum Handler {
    Fn(NativeHandler),
    Closure(HostClosure),
}

#[derive(Default, Clone)]
pub struct NativeRegistry {
    handlers: std::collections::HashMap<u32, Handler>,
    pending: Rc<RefCell<Vec<Job>>>,
}

impl NativeRegistry {
    // ... existing new/set_pending/take_pending unchanged ...

    /// Registers a fn-pointer handler at `index`.
    pub fn register(&mut self, index: u32, handler: NativeHandler) {
        self.handlers.insert(index, Handler::Fn(handler));
    }

    /// Registers a capturing closure at `index`.
    pub fn register_closure(&mut self, index: u32, closure: HostClosure) {
        self.handlers.insert(index, Handler::Closure(closure));
    }

    /// Dispatches a native call (closure slots borrow_mut for the call).
    pub fn dispatch(
        &mut self,
        heap: &mut Heap,
        this: JsValue,
        args: &[JsValue],
        index: u32,
    ) -> Result<JsValue, JsValue> {
        match self.handlers.get(&index).cloned() {
            Some(Handler::Fn(handler)) => handler(heap, this, args),
            Some(Handler::Closure(closure)) => (closure.borrow_mut())(heap, this, args),
            None => {
                let msg = format!("TypeError: native function #{index} is not registered");
                let h = heap.intern_string(v12_heap::V12Str::latin1(msg.into_bytes()));
                Err(JsValue::string(h))
            }
        }
    }
}
```

```rust
/// Index space reserved for host functions created through the embedding
/// API. Well above any realistic program function count; the interpreter
/// dispatches any index >= functions.len() to the native registry
/// (`v12-interp/src/lib.rs:1485`).
const HOST_FN_BASE: u32 = 0x1000_0000;

impl Engine {
    fn next_host_index(&mut self) -> u32 {
        self.host_fn_counter += 1; // add `host_fn_counter: u32` field, init 0 in both constructors
        HOST_FN_BASE + self.host_fn_counter - 1
    }

    /// Creates a global function backed by a Rust closure.
    ///
    /// The function is installed as a property named `name` on the realm's
    /// global object and dispatches through the engine's native registry.
    pub fn create_host_function(
        &mut self,
        name: &str,
        closure: crate::builtins::HostClosure,
    ) -> Result<(), JsValue> {
        let index = self.next_host_index();
        self.registry.register_closure(index, closure);
        let global = self.realm.global();
        let func = self.heap.alloc(v12_heap::JsObject {
            kind: v12_heap::KIND_FUNCTION,
            elements: vec![JsValue::from_i32_smi(index as i32).unwrap()],
            prototype: None,
            ..Default::default()
        });
        self.heap.add_root(JsValue::object(func));
        // Define `name` on the global object using the public shape API
        // (`Heap::add_property` + `Heap::lookup_property` from `v12-heap`),
        // the same mechanism the interpreter uses for `SetGlobal`. This avoids
        // depending on private interpreter internals.
        let key = self.heap.intern_string(v12_heap::V12Str::latin1(name.as_bytes().to_vec()));
        let prop_key = v12_heap::PropKey::from_string(key);
        // Fast path: if the property already exists on the global shape, just
        // write the slot. Otherwise do a shape transition.
        let global_shape = self.heap.shape_of(global);
        if let Some(desc) = self.heap.lookup_property(global_shape, prop_key)
            && let Some(slot) = desc.slot()
        {
            // Property exists: direct slot write (matching interpreter fast path)
            let idx = if Some(global) == self.realm.global() { // realm has only one global
                v12_interp::GLOBAL_VAR_OFFSET + slot as usize
            } else {
                slot as usize
            };
            if idx < self.heap.get_mut(global).properties.len() {
                self.heap.get_mut(global).properties[idx] = JsValue::object(func);
            }
        } else {
            // New property: shape transition + allocate slot
            let new_shape = self.heap.add_property(global_shape, prop_key, v12_heap::Attrs::default());
            let slot_idx = self.heap.lookup_property(new_shape, prop_key).unwrap().slot().unwrap() as usize;
            let prop_idx = v12_interp::GLOBAL_VAR_OFFSET + slot_idx;
            // Grow properties vec if needed
            let obj = self.heap.get_mut(global);
            if prop_idx >= obj.properties.len() {
                obj.properties.resize(prop_idx + 1, JsValue::undefined());
            }
            obj.properties[prop_idx] = JsValue::object(func);
            // Update global's shape so subsequent GetGlobal uses the new shape
            // (interpreter caches shape per-frame; we rebuild interp each eval anyway).
        }
        Ok(())
    }
}
```

If the direct shape manipulation above is too coupled to interpreter internals, the simpler fallback is to use the existing `Eval` path: `eval("globalThis.name = function() { ... }")` — but that defeats the purpose of a direct API. The shape API in `v12-heap` is public and stable; use it.

Add a `v12-engine` unit test (in `engine.rs` tests or `tests.rs`) that installs a closure via `create_host_function` and asserts `eval("name()")` dispatches — this pins the global-define + index-routing path inside the engine, independent of the API crate.

```rust
/// Calls the global function `name` with `args` using the retained program
/// of the most recent eval.
///
/// Requires a prior `eval` in this engine (the retained program provides
/// the bytecode for `name` and any functions it calls).
pub fn call_global(&mut self, name: &str, args: &[JsValue]) -> Result<JsValue, JsValue> {
    let retained = match &self.retained {
        Some(r) => (r.functions.clone(), r.main, r.strings.clone()),
        None => {
            let h = self.heap.intern_string(V12Str::latin1(
                b"ReferenceError: no evaluated program".to_vec(),
            ));
            return Err(JsValue::string(h));
        }
    };
    let global = self.realm.global();
    self.heap.add_root(JsValue::object(global));
    // Resolve `name` on the global object using the public shape API.
    // Mirrors `op_get_global` (v12-interp/src/lib.rs:2598): lookup property
    // on the global's shape, then read the slot with GLOBAL_VAR_OFFSET bias.
    let key = self.heap.intern_string(V12Str::latin1(name.as_bytes().to_vec()));
    let prop_key = v12_heap::PropKey::from_string(key);
    let global_shape = self.heap.shape_of(global);
    let desc = self.heap.lookup_property(global_shape, prop_key);
    let slot = desc.and_then(|d| d.slot()).ok_or_else(|| {
        let h = self.heap.intern_string(V12Str::latin1(
            format!("ReferenceError: {name} is not defined").into_bytes(),
        ));
        JsValue::string(h)
    })?;
    let prop_idx = v12_interp::GLOBAL_VAR_OFFSET + slot as usize;
    let func = self.heap.get(global).properties.get(prop_idx).copied()
        .ok_or_else(|| {
            let h = self.heap.intern_string(V12Str::latin1(
                format!("ReferenceError: {name} is not defined").into_bytes(),
            ));
            JsValue::string(h)
        })?;
    // Verify it's a callable function object
    if !func.is_object() {
        let h = self.heap.intern_string(V12Str::latin1(
            b"TypeError: global binding is not a function".to_vec(),
        ));
        return Err(JsValue::string(h));
    }
    self.heap.add_root(func);
    let heap = std::mem::replace(&mut self.heap, Heap::new(GcPolicy::NoGC));
    let (functions, main, strings) = retained;
    let mut interp = Interp::new_with_heap(heap, Some(global), functions, main, strings);
    interp.set_global_shape(self.global_shape);
    interp.set_natives(Box::new(self.registry.clone()));
    // Verify Interp::call_object signature at v12-interp/src/lib.rs:712
    // Expected: call_object(&mut self, fn_obj: JsValue, this: JsValue, args: &[JsValue])
    let result = interp.call_object(func, JsValue::undefined(), args);
    self.global_shape = interp.global_shape();
    self.heap = interp.into_heap();
    self.adopt_pending();
    self.run_jobs(); // settle any microtasks the call enqueued
    result
}
```

The property read uses **only public `v12-heap` APIs** (`shape_of`, `lookup_property`, direct `properties` vector access). No private interpreter helpers needed. use v12_api::Context;

```rust
fn main() -> Result<(), Box<dyn std::error::Error>> {
    let rt = v12_api::Runtime::builder().build();

    let mut ctx = rt.spawn();
    ctx.register_fn("log", |heap, _this, args| {
        let mut out = String::new();
        for (i, a) in args.iter().enumerate() {

            } else {

            }
        }
        println!("[js] {out}");
        Ok(v12_engine::JsValue::undefined())
    })?;

    let sum: f64 = ctx.call("add", &[1.5, 2.5])?;
```
