# Phase 1 (Freeze) grandfather list — see scripts/freeze-lint.sh.
#
# Format: one entry per grandfathered site: "<TAG> <file>:<line> # <reason>".  The
# reason is the literal error text (ERR_VAL) or the shape of the write, so the
# list describes the debt rather than merely counting it.
# TAG is one of: PK_PUSH | PROP_GET1 | ERR_VAL.
#
# Matching rule (see the script header): a file listed for a TAG stays legal for
# that TAG, but its hit COUNT must not grow past the number of entries below.
# :line numbers are documentary (they drift with edits); enforcement is
# file-membership + per-file count cap.  Any hit in an unlisted file fails.
# Test code is out of scope for all three TAGs and is excluded by path by the
# script, so it needs no entries here.
#
# ===================== RATCHET POLICY =====================
# Re-baselined 2026-10-01 (Track 0 / W0.2).  The previous list was generated
# 2026-09-06 and nothing had run the guard since, so it drifted: 67 entries
# against 129 real sites (62 unaccounted for), plus one stale PROP_GET1 entry
# pointing at a call_setup.rs site that had already been migrated.
# Decision: raise every cap ONCE to the measured current count, then only
# ratchet DOWN.  Concretely:
#   * Do not raise a cap again.  A new site in an allowlisted file fails and
#     must either be ported or, if genuinely unavoidable, reviewed as an
#     explicit cap raise with a reason here.
#   * Each migration commit DELETES the entries it retired; the cap follows
#     automatically because the script counts entries.
#   * This file must therefore shrink monotonically from here.  The stages were
#     call_setup.rs 53 -> 0 (DONE, W0.2c batch 1), then object_ops.rs 20 -> 0
#     and property.rs 16 -> 0 (DONE, W0.2c batch 2).  What is left is
#     lib.rs 8, generator_async.rs 7, execute.rs 5, call_capability.rs 5,
#     eval_context.rs 3, and ops.rs / module_loader.rs 1 each — batch 3.
#     ERR_VAL is 30 now (was 119); the other 14 are PK_PUSH/PROP_GET1 and
#     never move again.
#
# ===================== MIGRATION TARGETS =====================

#     and each site becomes a bare message argument.
#   interpreter layer: Ctx is UNREACHABLE from crates/v12-interp — v12-engine

#     v12-bytecode, v12-heap, v12-native only).  The reachable shared target is
